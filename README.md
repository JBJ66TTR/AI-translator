# 🌍 AI Translator

AI Translator is a small web project I built as a hobby while exploring AI-powered applications and interactive websites.

The project allows users to enter text and work with different translation options through a simple interface.

## ✨ Features

* Text input
* Language selection
* Translation functionality
* Simple interactive interface
